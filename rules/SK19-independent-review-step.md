## Independent review after the author's audit

After the author's audit (the Mandatory Style Audit, steps a–c), for a section draft or non-trivial rewrite, run the **independent adversarial red-team** (the Red-Team Protocol below): a reviewer that did NOT write the text re-runs the Mechanical Gate and applies `author_profile/gate_semantic.md` (define-before-use, followability, thesis-tie, lexical + decomposition consistency, non-duplication, mappability, honest positioning, and the closure gate) with a fresh-reader lens, returning a findings list, not a yes/no. This step also includes the four lens passes of `gate_semantic.md` S29, each run by its own fresh reviewer in addition to this one. Hand the red-team the rendered page images from the artifact gate, not only the `.tex`, so it can catch layout and float defects a source read cannot. Per the Semantic Gate's **closure gate** (S31), iterate the red-team after every substantive change until a final closure reviewer returns zero CRITICAL/MAJOR; never defer residual items as "done."
