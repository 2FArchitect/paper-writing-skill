## Claim-Evidence Alignment (Principle 1: the introduction promises what the evaluation shows)
- [ ] Can you list **every claim** the introduction makes?
- [ ] Does each claim have a **dedicated evaluation subsection**?
- [ ] If the paper makes **two types of claims** (e.g., system correctness + downstream improvement), are they in **separate evaluation sections**? (Principle 9: one claim type per evaluation section)
- [ ] Can each subsection be described as: "This section shows that [specific claim]"?
